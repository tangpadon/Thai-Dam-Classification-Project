
คู่มือการใช้งาน: DATASET PIPELINE (ระบบสร้างและเตรียมชุดข้อมูลพยากรณ์น้ำเขื่อน)


1. ภาพรวมระบบ
  โฟลเดอร์นี้รวบรวมเครื่องมือและสคริปต์สำหรับการสกัด จัดการ เติมเต็มค่าสูญหาย
  และสร้างชุดข้อมูลในรูปแบบมาตรฐาน Weka ARFF (.arff) จากข้อมูลสถานการณ์น้ำรายวัน
  ของเขื่อน 35 แห่งทั่วประเทศ (Open API กรมชลประทาน)
  เพื่อใช้ในการฝึกสอนและทดสอบ แบบจำลอง Machine Learning
  สำหรับพยากรณ์ความเสี่ยงน้ำล่วงหน้า 7 วัน และ 30 วัน


2. ขั้นตอนการติดตั้งและการรันระบบ 
  ขั้นตอนที่ 1: เปิด Terminal และเข้าสู่โฟลเดอร์ dataset_pipeline
    cd dataset_pipeline

  ขั้นตอนที่ 2: ติดตั้งไลบรารี Python ที่ต้องใช้
    pip install -r requirements.txt

  ขั้นตอนที่ 3: สั่งรันสคริปต์เพื่อสร้างชุดข้อมูล
    python build_training_arff.py

  เมื่อสคริปต์ทำงานเสร็จสิ้น ไฟล์ .arff ทั้ง 4 ไฟล์จะถูกบันทึกลงในโฟลเดอร์ datasets/ 


3. รายละเอียดฟีเจอร์และเกณฑ์การจำแนกความเสี่ยง
ฟีเจอร์ที่สร้างขึ้นสำหรับโมเดล
  1. percent_storage : ร้อยละปริมาตรน้ำเทียบกับความจุเก็บกัก ณ วันปัจจุบัน
  2. inflow_pct      : สัดส่วนน้ำไหลเข้าเทียบกับความจุเขื่อน ((inflow / capacity) * 100)
  3. outflow_pct     : สัดส่วนน้ำระบายออกเทียบกับความจุเขื่อน ((outflow / capacity) * 100)
  4. month           : ลำดับเดือน (1 - 12) เพื่อช่วยโมเดลจับรูปแบบฤดูกาล
  5. ข้อมูลกายภาพ     : capacity, storage, active_storage, volume, inflow, outflow
  6. ข้อมูลประจำเขื่อน : id, name, region, owner

เกณฑ์จำแนกระดับความเสี่ยงเป้าหมาย
  - drought (เสี่ยงน้ำแล้ง) : ร้อยละความจุในอนาคต น้อยกว่า 30%
  - normal  (ระดับน้ำปกติ)  : ร้อยละความจุในอนาคต อยู่ระหว่าง 30% ถึง 80%
  - flood   (เสี่ยงน้ำท่วม)  : ร้อยละความจุในอนาคต มากกว่า 80%


4. การนำไฟล์ ARFF ไปใช้งานต่อในโปรแกรม Weka
  1. เปิดโปรแกรม Weka -> เลือกเมนู Explorer -> แท็บ Preprocess
  2. กด Open file... แล้วเลือกไฟล์ชุดฝึกสอนจากโฟลเดอร์ datasets/ เช่น:
    - dam_risk_forecast_7days_train.arff
  3. ไปที่แท็บ Classify เพื่อเลือกโมเดลที่ต้องการทดสอบ:
    - Logistic Regression : classifiers -> functions -> Logistic
    - Random Forest       : classifiers -> trees -> RandomForest
  4. ในส่วน Test options:
    - ติ๊กเลือก "Supplied test set"
    - กดปุ่ม Set... แล้ว Browse เลือกไฟล์ทดสอบคู่กัน (เช่น dam_risk_forecast_7days_test.arff)
  5. กดปุ่ม Start เพื่อเริ่มการประเมินผล (ดูค่า Accuracy, F-Measure, Confusion Matrix)
  6. เมื่อได้ผลลัพธ์ที่พึงพอใจ สามารถคลิกขวาที่ผลลัพธ์ใน Result list แล้วเลือก
    "Save model" เพื่อบันทึกเป็นไฟล์ .model (เช่น Log_7days.model หรือ RF_30days.model)
    แล้วนำไฟล์ไปวางไว้ที่ dashboard/models/trained/ เพื่อให้เว็บแดชบอร์ดโหลดไปใช้งาน
